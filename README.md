# Portfolio Website

A personal portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm run dev
```

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Resume file

The resume shortcuts expect the file at `public/resume.pdf`. Add the real PDF at that
path when it is ready; the project intentionally does not include a placeholder resume.
